# PayPal-AI 

> Integrate the PayPal developer platform with AI to build innovative applications.

---

## 📋 Requirements

### What to Build
Build or update an application that integrates the **PayPal developer platform** (using the free sandbox environment) along with an **AI tool, model, or platform** of your choice.

You may also incorporate tools from our featured sponsors:
* AG Grid
* APIMatic
* Astropods
* Bryntum
* Channel3
* Elastic
* KERNEL
* Postman
* Render
* Zapier

---

## 📦 What to Submit

### 1. Project
* Built with the required developer tools and meeting the project requirements above.

### 2. Text Description
* Explain your project's features, functionality, and use case.

### 3. Functional Demo
Judges must be able to actually run or interact with a working build. Satisfy this with **either**:
* **Clear, complete setup and run instructions** in your code repository so judges can build and run it themselves, **OR**
* A **hosted demo URL**.
> ⚠️ *Note: A design mockup, static prototype, or non-functional demo does not meet this requirement.*

### 4. Tools Used
* Identify which models or AI services were used and explain how they were integrated into your project workflow.

### 5. Public Code Repository
* **Platform:** GitHub, GitLab, or Bitbucket.
* **Contents:** Must contain all source code, assets, and instructions needed to run the project.
* **Open Source:** Must be public, with a visible license file at the top of the repository (in the About section).

### 6. Demo Video
* **Duration:** Under 3 minutes (judges are not required to watch past this mark).
* **Scope:** Must show the project functioning live on the device it was built for.
* **Hosting:** Uploaded to YouTube as publicly visible, with the link included on the submission form.
* **Compliance:** Must not include third-party trademarks or copyrighted music/material without permission.

## 🛠️ Getting Started (Template)

```bash
# Clone the repository
git clone https://github.com/your-username/PayPal-AI.git

# Navigate to the project directory
cd PayPal-AI

# Install dependencies
npm install

# Run the application
npm run dev
```
